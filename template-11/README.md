# FORMA HOUSE — Independent Hotel Concept

A distinct multi-page boutique hotel demo inspired by editorial architecture and bold contemporary typography.

## Run
Open `index.html` in a browser. No build process or backend required. External Google Fonts and Unsplash images require internet access.

## Pages
Home, Rooms, Room Details, Experiences, Dining, Spa, Gym, Events, Booking, Contact, Login, Forgot Password.

## Demo mode
All room rates, inventory, events, hotel details, contact messages, authentication, payment interactions and receipts are simulated. No real APIs, transactions, messages or credentials.

## Replace with live services later
Sample inventory and rates are in `assets/data.js`. UI logic and simulated workflows are in `assets/app.js`. Design tokens are CSS variables in `assets/style.css`. Replace mock data and handlers with dedicated service adapters before production.

## Design
Distinctive left navigation rail, asymmetrical hero, oversized sans-serif type, warm paper palette, vermilion accent, numbered editorial sections and horizontal room presentation.
