# luxury-stay-templates
Elegant and modern website templates for luxury hotels, shortlets, resorts, and premium stays.

Template 4 is a complete coastal-house concept with a sea-glass palette, selective glassmorphism, and its own responsive pages for rooms, experiences, dining, spa, gym, events, contact, and booking.

Template 5 is a cinematic boutique-hotel website with a three-scene, scroll-pinned video hero, overlapping gradient cards for rooms, spa, dining, fitness, and events, matching image-led detail pages with shared side navigation, a dedicated stay-enquiry page, an in-house host feature, a contact section, and an off-canvas menu.
